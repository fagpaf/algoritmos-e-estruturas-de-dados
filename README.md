# 📚 Algoritmos e Estruturas de Dados

Repositório contendo implementações e resoluções de exercícios da disciplina de Algoritmos e Estruturas de Dados. Todo o código foi desenvolvido em C/C++.

## 📖 Ementa e Conteúdo Programático

O repositório está organizado acompanhando os tópicos da disciplina:

- **Análise de Algoritmos:** Complexidade assintótica e fundamentos.
- **Estruturas de Dados Básicas:** Arrays, Listas Encadeadas, Filas e Pilhas.
- **Busca e Ordenação:** Busca linear/binária, Mergesort, Quicksort, etc.
- **Tabelas de Dispersão (Hash).**
- **Árvores:** Árvores Binárias de Busca, Árvores AVL, Heaps e Heapsort.
- **Grafos e Algoritmos:** Busca em Largura/Profundidade, Caminhos Mínimos (Dijkstra, Bellman-Ford, Floyd-Warshall), Árvores Geradoras Mínimas (Prim, Kruskal).
- **Heurísticas para Problemas Intratáveis:** Backtracking, Branch & Bound, Programação Dinâmica.
